# adr

Portfolio website (multi-page) inspired by AuthKit style.

## Content setup (required assets)

Put these files into `public/` so the site can load them fast without bundling:

- **`public/11.jpg`**: your photo (shown in the header center). If missing, the site shows `AD`.
- **`public/resume.pdf`**: your resume PDF (used by the “Download resume (PDF)” button).

## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.
